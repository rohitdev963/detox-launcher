# Premium clock artwork provenance

Date: 2026-11-15

The cherry-blossom branches, petals, moon, mountain silhouettes and scenic
gradients used by the premium clock faces are original procedural vector
artwork authored directly in `src/com/ansub/tvhome/PremiumClockPainter.java`
for this Detox implementation. No anime characters, downloaded pictures,
reference-image pixels, external textures or third-party artwork are included.

The artwork is part of the project source and follows the project's existing
source terms. No separate third-party artwork license or attribution is needed.
This note does not change the project's license or grant rights to existing
unrelated media.

The clocks use the existing user-selected font. Bundled font files and their
existing OFL notices in `assets/fonts` are unchanged. No new fonts or artwork
assets are redistributed.

The optional host layout preview uses those existing fonts through Java2D. It
is validation output in `build/premium-clock-check/previews`, not an application
wallpaper or runtime asset.
