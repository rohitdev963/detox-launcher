# Detox Launcher 1.10.56 — first public edition

Package: `com.ansub.tvhome.rain` · versionCode: `112` · minimum Android API: `21`.

The public edition retains Detox's Home launcher, Gaming library, native clocks,
utility controls, remote/pointer navigation, wallpaper/video import, profiles and
backup features. It uses original lightweight samples instead of the maintainer's
undocumented entertainment media.

## Bundled samples

- **Aurora Veil**, **Twilight Peaks**, **Ember Horizon** — original 1080p stills.
- **Aurora Drift**, **Ember Drift** — original silent 8-second 1080p60 motion samples.
- No bundled music. Music controls are hidden; optional navigation sounds remain.

All five samples are MIT licensed and generated by the project's own artwork tool.
Existing third-party font and icon notices are included. Both build paths package
only the reviewed public asset allowlist, even if other files exist on the laptop.
The public source does not need Git LFS or private signing credentials.

## Compatibility and update behavior

App identity and the official release certificate are preserved. Imported photos,
video paths/URIs and unrelated saved settings are retained. An obsolete bundled
selection falls back to an original sample; a saved imported video takes precedence
over a stale bundled-video identity. A Gaming decoder failure falls back to an
original still without replacing the saved choice.

Use the signed APK and checksum attached to the actual GitHub release. See
[INSTALL.md](INSTALL.md). Source ZIPs and unsigned compile-check APKs cannot be
installed directly. Keep the stock launcher available; selecting Detox as default
Home depends on manufacturer support.

## Validation and limitations

46 host suites and targeted build/media tests pass. The original videos fully
decode as H.264, 1080p60, limited-range yuv420p, with no audio. Host Android stand-ins
verify lifecycle and typography behavior but do not replace actual hardware tests.

The maintainer reports their previous installed Detox build works on their TV.
The new public edition has not been installed as part of preparation, and no
every-TV compatibility or measured FPS guarantee is made. Treat the first public
publication as a preview until its new defaults are exercised on supported devices.
